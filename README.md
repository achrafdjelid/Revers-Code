# Number Reverse and Digit Sum in C

A simple C program that reads an integer, reverses its digits, calculates the sum of its digits, and adds both results together.

## Description

This program performs three main operations:

1. **Reverse the Number:** Reverses the digits of the input number.
2. **Calculate Digit Sum:** Calculates the sum of all digits.
3. **Calculate Final Output:** Adds the reversed number to the sum of its digits.

## Example

**Input:**
```text
Enter a number: 1234
```

**Process:**
- Original Number: `1234`
- Reversed Number: `4321`
- Sum of Digits: `1 + 2 + 3 + 4 = 10`
- Final Output: `4321 + 10 = 4331`

**Output:**
```text
Output = 4331
```
